    Vorgehen in der Prüfung

    Die ersten fünf Minuten

    1. Alles lesen, bevor Sie etwas tippen. Notieren Sie neben jeder Aufgabe Punkte und eine Zeitschätzung.
    2. Zeit nach Punkten verteilen: Bei 90 Minuten und 100 Punkten sind es rund 50 Sekunden pro Punkt. Eine 20-Punkte-Aufgabe darf etwa 15 Minuten kosten.
    3. Mit der sichersten Aufgabe beginnen. Sichere Punkte zuerst, das beruhigt.
    4. Klären Sie Unklarheiten sofort mit der Aufsicht, nicht erst am Ende.

    Pro Aufgabe

    1. Vorgaben wörtlich übernehmen: Klassennamen, Methodennamen, Parametertypen und Rückgabetypen exakt so, wie sie in der Aufgabe stehen. Automatische Tests und Korrektoren suchen genau diese Namen.
    2. Gerüst zuerst: Klasse und alle Methoden mit „leerem“ Rumpf anlegen und kompilieren lassen. Dann haben Sie ein lauffähiges Grundgerüst.
    3. Kleine Schritte: Nach jeder Methode kompilieren und in main mit System.out.println testen.
    4. Beispiel von Hand durchrechnen, bevor Sie die Schleife schreiben. Was soll bei {3, 5, 1} herauskommen?
    5. Randfälle: leeres Array oder leere Liste, null, ein einziges Element, 0, negative Zahlen, doppelte Werte.

    Wenn Sie nicht weiterkommen

    1. Lesen Sie die erste Fehlermeldung des Compilers, die folgenden sind oft Folgefehler. Die Zeilennummer zeigt, wo Sie suchen (siehe „Fehlermeldungen“).
    2. Geben Sie Zwischenwerte aus: System.out.println("i=" + i + " summe=" + summe);
    3. Vereinfachen Sie: Lösen Sie zuerst eine kleinere Version (nur positive Zahlen, nur ein Element).
    4. Suchen Sie mit / im Suchfeld dieser Datei nach dem Stichwort (zum Beispiel „Comparator“, „Map“, „split“).
    5. Nach fünf Minuten ohne Fortschritt: Kommentar schreiben, was fehlt, und zur nächsten Aufgabe wechseln. Kommen Sie später zurück.

    Teilpunkte sichern

    • Lauffähig vor perfekt: Ein Programm, das kompiliert und die Hälfte kann, bringt meist mehr Punkte als ein vollständiges mit Compilerfehler.
    • Nichts Kaputtes abgeben: Teile, die nicht kompilieren, auskommentieren (/* ... */) und mit einem Satz erklären, was geplant war.
    • Lesbar schreiben: Sprechende Namen, Einrückung, kurze Kommentare bei Tricks. Das hilft beim Debuggen und bei der Bewertung.
    • Hilfsmethoden erlaubt, wenn nichts anderes verlangt ist. Zerlegen Sie große Aufgaben.
    • Ausgaben genau so, wie verlangt (Leerzeichen, Groß/Klein, Komma). Eine zusätzliche Ausgabe kann Tests brechen.

    Die letzten zehn Minuten

    1. Alles speichern und noch einmal komplett kompilieren und starten.
    2. Überflüssige Testausgaben und main-Experimente entfernen (oder klar kennzeichnen), wenn die Aufgabe das verlangt.
    3. Dateinamen, Paketnamen und Abgabeformat prüfen (genau eine Datei? Zip? Name/Matrikelnummer im Kommentar?).
    4. Offene Aufgaben mit einem Kommentar sichern, statt sie leer zu lassen.

    Vom Text zum Code: ein Schema

    Fast jede Aufgabe lässt sich so zerlegen. Schreiben Sie die Antworten als Kommentare in den Code, bevor Sie programmieren.

// 1. Eingabe?      String satz
// 2. Ausgabe?      int (Anzahl Wörter)
// 3. Beispiel?     "  viele   Worte hier " -> 3
// 4. Randfälle?    "" -> 0, nur Leerzeichen -> 0
// 5. Idee?         trim; wenn leer 0; sonst split("\\s+") und Länge nehmen
static int wortAnzahl(String satz) {
    String t = satz.trim();
    if (t.isEmpty()) return 0;
    return t.split("\\s+").length;
}

    Lesen Sie immer ganze Zeilen mit nextLine() und wandeln Sie danach um. Das vermeidet das bekannte Problem mit nextInt() und nextLine() (siehe „Typische Denkfehler“).

        System.out.print("Name: ");
        String name = sc.nextLine();
        System.out.println("alter=" + alter + ", name='" + name + "'");
    }
}

    Konsolenmenü mit Schleife und switch

    Wiederholt Eingaben, bis der Benutzer 0 wählt. Ungültige Eingaben werden abgefangen. Funktioniert für fast jede „Verwaltungsaufgabe“ (Liste, Konto, Lager).

    import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Menue {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        List<String> aufgaben = new ArrayList<>();
        boolean laeuft = true;

        while (laeuft) {
            System.out.println("\n1) Neu  2) Anzeigen  3) Loeschen  0) Ende");
            System.out.print("Wahl: ");
            String eingabe = sc.nextLine().trim();

            switch (eingabe) {
                case "1" -> {
                    System.out.print("Text: ");
                    aufgaben.add(sc.nextLine());
                }
                case "2" -> {
                    if (aufgaben.isEmpty()) System.out.println("(leer)");
                    for (int i = 0; i < aufgaben.size(); i++) {
                        System.out.println((i + 1) + ". " + aufgaben.get(i));
                    }
                }
                case "3" -> {
                    System.out.print("Nummer: ");
                    try {
                        int nr = Integer.parseInt(sc.nextLine().trim());
                        aufgaben.remove(nr - 1);
                    } catch (NumberFormatException | IndexOutOfBoundsException e) {
                        System.out.println("Ungueltige Nummer");
                    }
                }
                case "0" -> laeuft = false;
                default -> System.out.println("Unbekannte Eingabe");
            }
        }
        System.out.println("Tschuess");
    }
}

    Klasse mit allem Üblichen

    public class Person implements Comparable<Person> {
    private final String name;
    private int alter;

    public Person(String name, int alter) {
        if (alter < 0) throw new IllegalArgumentException("Alter < 0");
        this.name = name;
        this.alter = alter;
    }

    public String getName() { return name; }
    public int getAlter()   { return alter; }
    public void setAlter(int alter) { this.alter = alter; }

    @Override public int compareTo(Person o) {
        return Integer.compare(alter, o.alter);
    }
    @Override public boolean equals(Object o) {
        return o instanceof Person p && name.equals(p.name) && alter == p.alter;
    }
    @Override public int hashCode() { return java.util.Objects.hash(name, alter); }
    @Override public String toString() { return name + " (" + alter + ")"; }
}

    Für reine Datenklassen genügt oft ein record Person(String name, int alter) { }. Es erzeugt Konstruktor, Getter (name()), equals, hashCode und toString automatisch.

    Weitere kleine Muster (kompiliert und getestet)

    Enum mit switch, Record mit Prüfung, generische Methode, Varargs, Lambda mit default-Methode, Mehrfach-Sortierung, formatierte Ausgabe, 2D-Arrays, Zeichen zählen, Duplikate entfernen, Umwandlungen.

    import java.util.*;
import java.util.stream.*;

public class Schablonen {

    // --- Enum mit switch ---------------------------------------------------
    enum Wochentag { MO, DI, MI, DO, FR, SA, SO }

    static boolean istWochenende(Wochentag t) {
        return switch (t) {
            case SA, SO -> true;
            default -> false;
        };
    }

    // --- Record mit Validierung --------------------------------------------
    record Punkt(int x, int y) {
        Punkt {
            if (x < 0 || y < 0) throw new IllegalArgumentException("negativ");
        }
        double abstandZumUrsprung() { return Math.sqrt(x * x + y * y); }
    }

    // --- Generische Methode ------------------------------------------------
    static <T extends Comparable<T>> T maximum(List<T> liste) {
        T best = liste.get(0);
        for (T t : liste) if (t.compareTo(best) > 0) best = t;
        return best;
    }

    // --- Varargs -----------------------------------------------------------
    static int summe(int... zahlen) {
        int s = 0;
        for (int z : zahlen) s += z;
        return s;
    }

    // --- Interface mit default-Methode und Lambda --------------------------
    interface Rechner {
        int rechne(int a, int b);
        default int verdoppeln(int a, int b) { return 2 * rechne(a, b); }
    }

    public static void main(String[] args) {
        System.out.println(istWochenende(Wochentag.SA) + " " + istWochenende(Wochentag.MO));
        System.out.println(new Punkt(3, 4).abstandZumUrsprung());
        System.out.println(maximum(List.of(3, 9, 4)) + " " + maximum(List.of("b", "z", "a")));
        System.out.println(summe() + " " + summe(1, 2, 3));
        Rechner plus = (a, b) -> a + b;
        System.out.println(plus.rechne(2, 3) + " " + plus.verdoppeln(2, 3));

        // Mehrfach sortieren: erst Länge, dann alphabetisch
        List<String> woerter = new ArrayList<>(List.of("kiwi", "fig", "apple", "pear", "date"));
        woerter.sort(Comparator.comparingInt(String::length).thenComparing(Comparator.naturalOrder()));
        System.out.println(woerter);

        // Zufall reproduzierbar (Seed) und Würfeln 1..6
        Random r = new Random(42);
        int wurf = r.nextInt(6) + 1;
        System.out.println(wurf >= 1 && wurf <= 6);

        // Formatierte Ausgabe
        System.out.printf("%-8s|%6.2f|%05d|%,d%n", "Name", 3.14159, 42, 1234567);
        System.out.println(String.format("%3d%%", 7));

        // 2D-Array ausgeben
        int[][] g = new int[3][4];
        for (int i = 0; i < g.length; i++)
            for (int j = 0; j < g[i].length; j++) g[i][j] = i * j;
        for (int[] zeile : g) System.out.println(Arrays.toString(zeile));

        // Zeichen zählen mit Array (nur a-z)
        int[] haeufig = new int[26];
        for (char c : "hello world".toCharArray()) {
            if (c >= 'a' && c <= 'z') haeufig[c - 'a']++;
        }
        System.out.println("l kommt " + haeufig['l' - 'a'] + "x vor");

        // Duplikate entfernen, Reihenfolge behalten
        List<Integer> mitDoppelten = List.of(3, 1, 3, 2, 1);
        System.out.println(new ArrayList<>(new LinkedHashSet<>(mitDoppelten)));
        System.out.println(mitDoppelten.stream().distinct().sorted().toList());

        // Liste in Array und zurück
        Integer[] feld = mitDoppelten.toArray(new Integer[0]);
        System.out.println(feld.length + " " + Arrays.asList(feld));
        int[] primitiv = mitDoppelten.stream().mapToInt(Integer::intValue).toArray();
        System.out.println(Arrays.stream(primitiv).sum());

        // String <-> Zahl
        System.out.println(Integer.parseInt("42") + 1 + " " + String.valueOf(3.5) + " " + Integer.toBinaryString(10));

        // Ternary und StringBuilder
        int note = 2;
        System.out.println(note <= 4 ? "bestanden" : "nicht bestanden");
        StringBuilder sb = new StringBuilder("Java");
        sb.insert(0, ">> ").append(" <<").setCharAt(3, 'j');
        System.out.println(sb);
    }
}

    public class Statistik {

    static int summe(int[] a) {
        int s = 0;
        for (int x : a) s += x;
        return s;
    }

    static double durchschnitt(int[] a) {
        if (a.length == 0) return 0;          // Randfall: leeres Array
        return (double) summe(a) / a.length;  // Cast VOR der Division!
    }

    static int minimum(int[] a) {
        int min = a[0];
        for (int i = 1; i < a.length; i++) {
            if (a[i] < min) min = a[i];
        }
        return min;
    }

    static int maximum(int[] a) {
        int max = a[0];
        for (int x : a) {
            if (x > max) max = x;
        }
        return max;
    }

    static int anzahlUeberDurchschnitt(int[] a) {
        double avg = durchschnitt(a);
        int count = 0;
        for (int x : a) {
            if (x > avg) count++;
        }
        return count;
    }

        int[] zahlen = {4, 8, 15, 16, 23, 42};

        System.out.println("Maximum:      " + maximum(zahlen));

    Themen: Schleifen, Modulo, long

    Hinweise
    • Für istPrim reicht es, Teiler bis zur Wurzel von n zu testen (Bedingung i * i <= n).
    • Euklid: solange b != 0, ersetze (a, b) durch (b, a % b).
    • Quersumme: mit % 10 die letzte Ziffer holen, mit / 10 abschneiden.
    Lösung anzeigen
    public class Zahlen {

    static boolean istPrim(int n) {
        if (n < 2) return false;
        for (int i = 2; (long) i * i <= n; i++) {
            if (n % i == 0) return false;
        }
        return true;
    }

    static long fakultaet(int n) {
        long f = 1;
        for (int i = 2; i <= n; i++) f *= i;
        return f;
    }

    static long fibonacci(int n) {
        long a = 0, b = 1;
        for (int i = 0; i < n; i++) {
            long next = a + b;
            a = b;
            b = next;
        }
        return a;
    }

    static int ggt(int a, int b) {
        while (b != 0) {
            int rest = a % b;
            a = b;
            b = rest;
        }
        return a;
    }

    static int quersumme(int n) {
        n = Math.abs(n);
        int summe = 0;
        while (n > 0) {
            summe += n % 10;
            n /= 10;
        }
        return summe;
    }

    public static void main(String[] args) {
        System.out.print("Primzahlen bis 30:");
        for (int i = 1; i <= 30; i++) {
            if (istPrim(i)) System.out.print(" " + i);
        }
        System.out.println();
        System.out.println("10!        = " + fakultaet(10));
        System.out.println("fib(10)    = " + fibonacci(10));
        System.out.println("ggT(48,36) = " + ggt(48, 36));
        System.out.println("Quersumme(9875) = " + quersumme(9875));
    }

public class Matrix {

    static int[][] transponieren(int[][] m) {
        int[][] t = new int[m[0].length][m.length];
        for (int i = 0; i < m.length; i++) {
            for (int j = 0; j < m[i].length; j++) {
                t[j][i] = m[i][j];
            }
        }
        return t;
    }

        int[] summen = new int[m.length];
        for (int i = 0; i < m.length; i++) {
            for (int wert : m[i]) summen[i] += wert;
        }
        return summen;
    }

        int s = 0;
        for (int i = 0; i < m.length && i < m[i].length; i++) s += m[i][i];
        return s;
    }

            {1, 2, 3},
            {4, 5, 6}

    Übung 6 · Sortieren und Suchen Mittel

    Implementieren Sie bubbleSort(int[] a) (verändert das Array) und die binaereSuche(int[] a, int ziel), die den Index oder -1 liefert. Das Array muss dafür sortiert sein.

    Themen: Algorithmen, Arrays

    Hinweise
    • Bubble Sort: In jeder Runde wandert das größte Element nach hinten. Die innere Schleife wird pro Runde kürzer.
    • Binäre Suche: Mitte berechnen, vergleichen, die passende Hälfte behalten. Mitte als links + (rechts - links) / 2 verhindert Überlauf.
    Lösung anzeigen
    import java.util.Arrays;

public class Sortieren {

    static void bubbleSort(int[] a) {
        for (int runde = 0; runde < a.length - 1; runde++) {
            boolean getauscht = false;
            for (int i = 0; i < a.length - 1 - runde; i++) {
                if (a[i] > a[i + 1]) {
                    int tmp = a[i];
                    a[i] = a[i + 1];
                    a[i + 1] = tmp;
                    getauscht = true;
                }
            }
            if (!getauscht) break;   // schon sortiert
        }
    }

    // Voraussetzung: Array ist sortiert. Gibt den Index zurück, sonst -1.
    static int binaereSuche(int[] a, int ziel) {
        int links = 0, rechts = a.length - 1;
        while (links <= rechts) {
            int mitte = links + (rechts - links) / 2;
            if (a[mitte] == ziel) return mitte;
            if (a[mitte] < ziel) links = mitte + 1;
            else rechts = mitte - 1;
        }
        return -1;
    }

    public static void main(String[] args) {
        int[] a = {29, 4, 17, 8, 42, 15};
        bubbleSort(a);
        System.out.println(Arrays.toString(a));          // [4, 8, 15, 17, 29, 42]
        System.out.println(binaereSuche(a, 17));         // 3
        System.out.println(binaereSuche(a, 5));          // -1
    }
}

    Lösen Sie rekursiv: potenz(basis, exp), quersumme, umkehren (String), binaer (Dezimalzahl als Binärstring) und hanoiZuege. Erklären Sie, warum das rekursive fibonacci für große n langsam ist.

    Themen: Rekursion

    Hinweise
    • Jede Rekursion braucht eine Abbruchbedingung und einen Schritt, der dem Abbruch näher kommt. Sonst: StackOverflowError.
    • Binär: binaer(n / 2) + (n % 2).
    • Naives Fibonacci rechnet dieselben Teilprobleme immer wieder: exponentiell viele Aufrufe.
    Lösung anzeigen
    public class Rekursion {

    static long potenz(long basis, int exp) {
        if (exp == 0) return 1;                  // Abbruchbedingung
        return basis * potenz(basis, exp - 1);   // Rekursionsschritt
    }

    static int quersumme(int n) {
        if (n < 10) return n;
        return n % 10 + quersumme(n / 10);
    }

    static String umkehren(String s) {
        if (s.length() <= 1) return s;
        return umkehren(s.substring(1)) + s.charAt(0);
    }

    static String binaer(int n) {
        if (n < 2) return String.valueOf(n);
        return binaer(n / 2) + (n % 2);
    }

    static int hanoiZuege(int scheiben) {
        if (scheiben == 0) return 0;
        return 2 * hanoiZuege(scheiben - 1) + 1;
    }

    static long fibonacci(int n) {              // langsam: exponentiell viele Aufrufe!
        if (n < 2) return n;
        return fibonacci(n - 1) + fibonacci(n - 2);
    }

        System.out.println(potenz(2, 10));      // 1024

    import java.util.*;

public class KlausurNoten {
    private final Map<String, List<Integer>> noten = new HashMap<>();

    void eintragen(String name, int note) {
        if (note < 1 || note > 6) throw new IllegalArgumentException("Ungueltige Note: " + note);
        noten.computeIfAbsent(name, k -> new ArrayList<>()).add(note);
    }

    double durchschnitt(String name) {
        List<Integer> liste = noten.get(name);
        if (liste == null) throw new NoSuchElementException("Unbekannt: " + name);
        double summe = 0;
        for (int n : liste) summe += n;
        return summe / liste.size();
    }

    String bester() {
        String best = null;
        for (String name : noten.keySet()) {
            if (best == null || durchschnitt(name) < durchschnitt(best)) best = name;
        }
        return best;
    }

    // Wie oft kommt jede Note vor? (sortiert nach Note)
    Map<Integer, Integer> verteilung() {
        Map<Integer, Integer> v = new TreeMap<>();
        for (List<Integer> liste : noten.values()) {
            for (int n : liste) v.merge(n, 1, Integer::sum);
        }
        return v;
    }

    Best Practices

    Java

    • Felder private, Zugriff über Getter oder record
    • Immutability bevorzugen (final, List.of, record)
    • equals() und hashCode() immer zusammen überschreiben
    • Gegen Interfaces programmieren: List<String> l = new ArrayList<>()
    • try-with-resources für alles AutoCloseable
    • Keine leeren catch-Blöcke
    • Optional als Rückgabetyp statt null
    • Namen: Klassen PascalCase, Methoden camelCase, Konstanten UPPER_SNAKE_CASE

    JDBC & Spring

    • SQL nur mit PreparedStatement, nie mit String-Konkatenation
    • Verbindungen über einen Pool, immer schließen
    • Konstruktor-Injektion statt Feld-@Autowired
    • Entities nicht direkt als API-Antwort, lieber DTOs oder Records
    • Transaktionen im Service, nicht im Controller
    • Passwörter und Schlüssel über Umgebungsvariablen, nicht in Git
    • ddl-auto: validate plus Flyway/Liquibase für Schema-Änderungen
    • LAZY-Beziehungen beachten (N+1-Problem, JOIN FETCH)
