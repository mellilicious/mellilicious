    Tipps für die Prüfung

    Die Regeln Ihrer Übungsblätter

    • Das Programm muss kompilieren und ausführbar sein. Das ist die Voraussetzung für jede Bewertung. Ein Programm mit Compilerfehler bringt 0 Punkte.
    • Ausgabe exakt wie verlangt: Groß/Klein, Satzzeichen, Leerzeichen, Zeilenumbrüche. „Number 1: “ mit Leerzeichen nach dem Doppelpunkt.
    • Aufforderungen zur Eingabe mit print, alles andere mit println.
    • Vorgegebenes Grundgerüst verwenden, keine Namen ändern. Klassen-, Methoden- und Parameternamen so lassen. Methoden in App sind public static.
    • Vorgegebene Testdateien (AppTest.java) oder der .github-Ordner dürfen nicht verändert werden. Das gilt als K.O.-Kriterium.
    • Verbote beachten: „Keine API-Klassen“, „kein toUpperCase()“, „nur eine Scanner-Variable“. Wer verbotene Mittel nutzt, verliert Punkte, auch wenn die Ausgabe stimmt.

    Die ersten fünf Minuten

    1. Alles lesen, bevor Sie tippen. Punkte und Reihenfolge notieren.
    2. Mit der sichersten Aufgabe beginnen.
    3. Beispielausgaben der Aufgabe als Test nehmen: Ihr Programm muss genau das ausgeben.
    4. Unklarheiten sofort der Aufsicht stellen.

    Pro Aufgabe

    1. Gerüst zuerst: Klasse und leere Methoden anlegen und kompilieren.
    2. Beispiel von Hand durchrechnen, bevor Sie die Schleife schreiben.
    3. Kleine Schritte: nach jeder Methode kompilieren und mit einem Beispiel testen.
    4. Randfälle: 0, negative Zahl, eine einzige Eingabe, leerer String, Array mit einem Element.
    5. Ausgabe Zeichen für Zeichen mit dem Beispiel vergleichen (Leerzeichen am Zeilenende!).

    Die häufigsten Stolpersteine dieser Blätter

    • Ganzzahldivision: 7 / 2 ist 3. Für den Durchschnitt (double) summe / anzahl.
    • \ im String muss \\ geschrieben werden (ASCII-Art).
    • switch ohne break läuft in den nächsten Fall.
    • char + int ergibt int: mit (char) zurückwandeln.
    • Dezimalkomma: auf deutschem System erzeugt %.2f ein Komma, Scanner erwartet es auch bei der Eingabe.
    • Nur ein Scanner, und nach nextInt() vor nextLine() den Rest der Zeile lesen.
    • Off-by-one: < oder <=? Mit dem kleinsten Beispiel (n=1) prüfen.
    • Endlosschleife: wird die Variable in der Bedingung in der Schleife verändert?
    • Unvollständige letzte Zeile (Kalender): die Zeile muss trotzdem mit println() beendet werden.

    Wenn Sie nicht weiterkommen

    1. Lesen Sie die erste Fehlermeldung, die folgenden sind oft Folgefehler (siehe „Fehlermeldungen“).
    2. Zwischenwerte ausgeben: System.out.println("i=" + i + " summe=" + summe);
    3. Kleineres Problem zuerst lösen (nur n=1, nur ein Wert).
    4. Suchen Sie mit / in dieser Datei nach dem Stichwort.
    5. Nach fünf Minuten ohne Fortschritt: Kommentar schreiben, was fehlt, nächste Aufgabe, später zurückkehren.

    Die letzten zehn Minuten

    1. Alles speichern und noch einmal komplett kompilieren und starten.
    2. Nicht kompilierende Teile auskommentieren und kurz erklären, was geplant war.
    3. Test- und Debug-Ausgaben entfernen, wenn die Aufgabe eine exakte Ausgabe verlangt.

    Einlesen mit Scanner

    Ein Scanner pro Programm. Prompts mit print. Nach next() oder nextInt() den Rest der Zeile mit nextLine() verwerfen, bevor Sie eine ganze Zeile lesen.

    import java.util.Scanner;

public class Grundgeruest {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);      // genau ein Scanner pro Programm

        System.out.print("Zahl: ");                // Prompt: print, KEIN println
        int n = sc.nextInt();                      // ganze Zahl
        System.out.print("Kommazahl: ");
        double d = sc.nextDouble();                // Dezimaltrennzeichen: laut Systemeinstellung
        System.out.print("Zeichen: ");
        char c = sc.next().charAt(0);              // ein einzelnes Zeichen
        sc.nextLine();                             // Rest der Zeile wegwerfen ...
        System.out.print("Text: ");
        String s = sc.nextLine();                  // ... bevor eine ganze Zeile gelesen wird

        System.out.println(n + " " + d + " " + c + " " + s);
    }
}

    Schleifen-Muster

    Dreieck, zentrierte Pyramide, Zähler über zwei Schleifen. Das Prinzip: außen die Zeile, innen die Spalte, nach der inneren Schleife println().

    public class Muster {
    public static void main(String[] args) {
        int n = 4;

        // 1) Rechtwinkliges Dreieck: in Zeile z stehen z Sterne
        for (int z = 1; z <= n; z++) {
            for (int i = 0; i < z; i++) {
                System.out.print("*");
            }
            System.out.println();                  // Zeilenumbruch NACH der inneren Schleife
        }
        System.out.println();

        // 2) Zentriert: erst Leerzeichen, dann Zeichen
        for (int z = 1; z <= n; z++) {
            for (int i = 0; i < n - z; i++) {
                System.out.print(" ");
            }
            for (int i = 0; i < 2 * z - 1; i++) {
                System.out.print("*");
            }
            System.out.println();
        }
        System.out.println();

        // 3) Zaehler ueber beide Schleifen hinweg
        int zahl = 1;
        for (int z = 1; z <= n; z++) {
            for (int i = 1; i <= z; i++) {
                System.out.print(zahl++ + " ");
            }
            System.out.println();
        }
    }
}

    Rechnen mit char

    Ein char ist ein Zahlencode. Mit (char) wandeln Sie das Rechenergebnis zurück in ein Zeichen.

    public class CharRechnen {
    public static void main(String[] args) {
        char c = 'H';
        System.out.println((int) c);                  // 72: Zeichencode
        System.out.println((char) 73);                // I: Code zu Zeichen
        System.out.println((char) (c + 1));           // I: Zeichen + int ergibt int, daher Cast
        System.out.println(c + 1);                    // 73 (!) ohne Cast bleibt es eine Zahl
        System.out.println('a' - 'A');                // 32: Abstand klein/gross
        System.out.println((char) (c - 'A' + 'a'));   // h: gross -> klein
        System.out.println('7' - '0');                // 7: Ziffernzeichen -> Zahl
        System.out.println((char) ('0' + 7));         // 7: Zahl -> Ziffernzeichen

        System.out.println(c >= 'A' && c <= 'Z');     // Grossbuchstabe?
        System.out.println(c >= '0' && c <= '9');     // Ziffer?

        // Alphabet durchlaufen
        for (char x = 'a'; x <= 'e'; x++) {
            System.out.print(x);
        }
        System.out.println();
    }
}

    Formatierte Ausgabe

    %d ganze Zahl, %f Kommazahl, %s Text, %n Zeilenumbruch, %% Prozentzeichen. Zahl zwischen % und Buchstabe: Mindestbreite. -: linksbündig, 0: mit Nullen auffüllen, .2: Nachkommastellen.

    public class Formatieren {
    public static void main(String[] args) {
        int zahl = 7;
        double d = 3.14159;
        String s = "abc";

        System.out.println(String.format("|%d|", zahl));        // |7|
        System.out.println(String.format("|%4d|", zahl));       // |   7|  rechtsbuendig, Breite 4
        System.out.println(String.format("|%-4d|", zahl));      // |7   |  linksbuendig
        System.out.println(String.format("|%04d|", zahl));      // |0007|  mit Nullen
        System.out.println(String.format("|%.2f|", d));         // |3.14|  2 Nachkommastellen
        System.out.println(String.format("|%8.3f|", d));        // |   3.142|
        System.out.println(String.format("|%s|", s));           // |abc|
        System.out.println(String.format("|%5s|", s));          // |  abc|
        System.out.printf("%2d %2d%n", 5, 10);                   // %n = Zeilenumbruch
        System.out.printf("%d%%%n", 50);                         // %% = Prozentzeichen
    }

    Methoden und Arrays als Parameter

    Primitive Werte werden kopiert, Arrays als Referenz übergeben. Rückgabewert mit return, void ohne.

    public class Methoden {
    // Rueckgabewert: Methode liefert etwas zurueck
    public static int quadrat(int x) {
        return x * x;
    }

    // void: kein Rueckgabewert, nur Wirkung (Ausgabe)
    public static void gruss(String name) {
        System.out.println("Hallo " + name);
    }

    // Primitive Typen werden KOPIERT: der Aufrufer sieht die Aenderung nicht
    public static void erhoehe(int x) {
        x = x + 1;
    }

    // Arrays werden als REFERENZ uebergeben: Aenderungen an Elementen sind sichtbar
    public static void erhoeheAlle(int[] a) {
        for (int i = 0; i < a.length; i++) {
            a[i] = a[i] + 1;
        }
    }

    // Array zurueckgeben
    public static int[] ersteN(int n) {
        int[] r = new int[n];
        for (int i = 0; i < n; i++) {
            r[i] = i + 1;
        }
        return r;
    }

    public static void main(String[] args) {
        System.out.println(quadrat(5));
        gruss("Anna");

        int z = 5;
        erhoehe(z);
        System.out.println(z);                     // 5, unveraendert

        int[] a = {1, 2, 3};
        erhoeheAlle(a);
        System.out.println(java.util.Arrays.toString(a));   // [2, 3, 4]
        System.out.println(java.util.Arrays.toString(ersteN(4)));
    }
}

    Aufgabe 1.3 · Verwendung von Literalen

    Gegeben: 'Z', 0xface, 012, 80L, 44e-1f, 5.5f, 8.88e1, 99.9. Deklarieren Sie zu jedem Literal eine Variable mit passendem Typ und eine int-Variable sum. Geben Sie die Summe aus (nur die Zahl). Die Summe darf nicht erst am Ende in int umgewandelt werden.

    Hinweise
    • Typ je Literal: Zeichen → char, 0x… → hexadezimal int, führende 0 → oktal int, L → long, f → float, e-Schreibweise ohne Suffix → double, Kommazahl ohne Suffix → double.
    • Jeden Summanden einzeln mit (int) casten. Der Cast schneidet Nachkommastellen ab (4.4 → 4, 88.8 → 88, 99.9 → 99).
    Lösung anzeigen (erst nach dem eigenen Versuch)
    public class Literale {
    public static void main(String[] args) {
        char a = 'Z';          // Zeichen, Wert 90
        int b = 0xface;        // hexadezimal (0x), Wert 64206
        int c = 012;           // oktal (fuehrende 0), Wert 10
        long d = 80L;          // long (L)
        float e = 44e-1f;      // 44 * 10^-1 = 4.4, float (f)
        float f = 5.5f;
        double g = 8.88e1;     // 8.88 * 10^1 = 88.8
        double h = 99.9;       // ohne Suffix: double

        // jedes Literal einzeln in int casten, dann addieren
        int sum = (int) a + b + c + (int) d + (int) e + (int) f + (int) g + (int) h;
        System.out.println(sum);
    }
}

    Ausgabe

    64582
    Warum so?
    • 0xface = 15·4096 + 10·256 + 15·16 + 14 = 64206. 012 ist oktal: 1·8 + 2 = 10, nicht 12. 44e-1f = 44 · 10-1 = 4.4. 'Z' hat den Zeichencode 90.
    • Summe: 90 + 64206 + 10 + 80 + 4 + 5 + 88 + 99 = 64582.

    Aufgabe 1.5 · Zahlen im Speicher vertauschen

    Vertauschen Sie zwei Variablen ohne dritte Hilfsvariable (mit + und -, alternativ XOR). „x: “ und „y: “ werden mit print ausgegeben.

    Hinweise
    • Dreischritt: x = x + y; y = x - y; x = x - y;
    • Rechnen Sie es mit x=9, y=4 auf Papier durch.
    Lösung anzeigen (erst nach dem eigenen Versuch)
    import java.util.Scanner;

public class Vertauschen {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Before Swap:");
        System.out.print("x: ");
        int x = sc.nextInt();
        System.out.print("y: ");
        int y = sc.nextInt();

        x = x + y;      // x = Summe
        y = x - y;      // y = altes x
        x = x - y;      // x = altes y

        System.out.println("After Swap:");
        System.out.println("x: " + x);
        System.out.println("y: " + y);
    }
}

y: 4
After Swap:

    Warum so?
    • Nach x = x + y steht in x die Summe (13). y = x - y ergibt 13 − 4 = 9, das alte x. x = x - y ergibt 13 − 9 = 4, das alte y. Alternative: x ^= y; y ^= x; x ^= y;

    Aufgabe 1.7 · Rating Sales Person

    Lesen Sie den Jahresumsatz ein. < 0 oder ≥ 100000: „Invalid Revenue“; 0 bis < 20000: „Poor Sales Revenue“; 20000 bis < 50000: „Average Sales Revenue“; 50000 bis < 80000: „Good Sales Revenue“; 80000 bis < 100000: „Excellent Sales Revenue“.

            System.out.println("Poor Sales Revenue");
        } else if (umsatz < 50000) {
            System.out.println("Average Sales Revenue");
        } else if (umsatz < 80000) {
            System.out.println("Good Sales Revenue");
        } else {
            System.out.println("Excellent Sales Revenue");
        }
    }
}

    Aufgabe 2.4 · Raute

    Geben Sie eine Raute aus, gesteuert von int h (Höhe, nur ungerade, sonst „Invalid number!“) und char c. In der Mitte steht c, links und rechts davon jeweils das nächst kleinere ASCII-Zeichen.

    Hinweise
    • Beide Werte zuerst einlesen, dann prüfen (so zeigt es das Beispiel).
    • Zeichen einlesen: sc.next().charAt(0)
    • mitte = h / 2. Für Zeile z ist k = mitte - Math.abs(mitte - z) der „Abstand zum Rand“: 0, 1, …, mitte, …, 1, 0.
    • Zeile: mitte - k Leerzeichen, dann Zeichen c-k … c aufsteigend, dann c-1 … c-k absteigend.
    • Mit (char) (c - i) erhalten Sie das i-te kleinere Zeichen.
    Lösung anzeigen (erst nach dem eigenen Versuch)
    import java.util.Scanner;

public class Raute {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("h: ");
        int h = sc.nextInt();
        System.out.print("c: ");
        char c = sc.next().charAt(0);

        if (h % 2 == 0) {
            System.out.println("Invalid number!");
            return;
        }
        int mitte = h / 2;
        for (int zeile = 0; zeile < h; zeile++) {
            int k = mitte - Math.abs(mitte - zeile);   // Abstand zum Rand: 0..mitte..0
            for (int i = 0; i < mitte - k; i++) {

                System.out.print((char) (c - i));
            }
            for (int i = 1; i <= k; i++) {             // wieder absteigend
                System.out.print((char) (c - i));
            }
            System.out.println();
        }
    }
}

    long x = seed;
    for (int i = 0; i < zahlen.length; i++) {
        x = (A * x + C) % M;
        zahlen[i] = x;
    }
    return zahlen;
}

    Aufgabe 3.4 · Swap Arrays

    • Die Referenzen selbst zu tauschen (a = b) würde nur die lokalen Parameter ändern, nicht die Arrays des Aufrufers.

    // Aufgabe 4: Arrays tauschen (ohne API-Klassen)
public static boolean swapArrays(int[] a, int[] b) {
    if (a.length != b.length) {
        return false;
    }
    for (int i = 0; i < a.length; i++) {
        int tmp = a[i];
        a[i] = b[i];
        b[i] = tmp;
    }
    return true;
}

    Aufgabe 3.5 · CamelCase

    Schreiben Sie String camelCase(String satz): Leerzeichen entfernen, jedes Wort beginnt groß, Großbuchstaben mitten im Wort werden klein, Satzzeichen werden entfernt (nur a–z, A–Z zählen). Verwenden Sie toCharArray() und rechnen Sie manuell mit char. toUpperCase(), replace() usw. sind verboten.

    Hinweise
    • Merken Sie sich mit einem boolean wortAnfang, ob der nächste Buchstabe ein Wortanfang ist.
    • Klein → groß: (char) (c - 'a' + 'A'). Groß → klein: (char) (c - 'A' + 'a') (oder jeweils ± 32).
    • Buchstabe prüfen: c >= 'a' && c <= 'z'.
    • Ein Leerzeichen setzt wortAnfang = true. Andere Zeichen (Apostroph, Punkt) werden einfach übersprungen.

    for (char c : satz.toCharArray()) {
        boolean klein = c >= 'a' && c <= 'z';
        boolean gross = c >= 'A' && c <= 'Z';

            } else if (!wortAnfang && gross) {
                c = (char) (c - 'A' + 'a');       // gross -> klein
            }
            sb.append(c);
            wortAnfang = false;
        }                                         // Satzzeichen: ignorieren
    }
    return sb.toString();
}

    Aufgabe 3.6 · Check Digit (Modulo 11)

    Array-Methoden

    Schreiben Sie maximum, durchschnitt, indexVon (-1 wenn nicht gefunden) und umdrehen (in place) für ein int[].

    Hinweise
    • Beim Umdrehen nur bis a.length / 2 laufen, sonst drehen Sie alles zweimal zurück.
    Lösung anzeigen
    public class ArrayStatistik {
    static int maximum(int[] a) {
        int max = a[0];
        for (int i = 1; i < a.length; i++) {
            if (a[i] > max) {
                max = a[i];
            }
        }
        return max;
    }

    static double durchschnitt(int[] a) {
        int summe = 0;
        for (int x : a) {
            summe += x;
        }
        return (double) summe / a.length;
    }

    static int indexVon(int[] a, int ziel) {
        for (int i = 0; i < a.length; i++) {
            if (a[i] == ziel) {
                return i;
            }
        }
        return -1;
    }

    static void umdrehen(int[] a) {
        for (int i = 0; i < a.length / 2; i++) {
            int tmp = a[i];
            a[i] = a[a.length - 1 - i];
            a[a.length - 1 - i] = tmp;
        }
    }

    public static void main(String[] args) {
        int[] z = {4, 8, 15, 16, 23, 42};
        System.out.println("max=" + maximum(z));
        System.out.println("schnitt=" + String.format("%.2f", durchschnitt(z)));
        System.out.println("index von 16: " + indexVon(z, 16) + ", von 99: " + indexVon(z, 99));
        umdrehen(z);
        System.out.println(java.util.Arrays.toString(z));
    }
}

    Caesar-Verschlüsselung

    Lesen Sie einen Text und eine Verschiebung ein. Buchstaben werden um shift im Alphabet verschoben (am Ende wieder von vorn), alles andere bleibt. Zählen Sie außerdem die Vokale. Ohne toUpperCase.

    Hinweise
    • (char) ('a' + (c - 'a' + shift) % 26)
    • Groß- und Kleinbuchstaben getrennt behandeln.
    • Text mit Leerzeichen: nextLine(). Die Zahl danach: Integer.parseInt(sc.nextLine().trim()).
    Lösung anzeigen
    import java.util.Scanner;

public class Caesar {
    static String verschluesseln(String text, int shift) {
        StringBuilder sb = new StringBuilder();
        for (char c : text.toCharArray()) {
            if (c >= 'a' && c <= 'z') {
                sb.append((char) ('a' + (c - 'a' + shift) % 26));
            } else if (c >= 'A' && c <= 'Z') {
                sb.append((char) ('A' + (c - 'A' + shift) % 26));
            } else {
                sb.append(c);                          // Leerzeichen etc. bleiben
            }
        }
        return sb.toString();
    }

    static int zaehleVokale(String text) {
        int n = 0;
        for (char c : text.toCharArray()) {
            if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u'
                    || c == 'A' || c == 'E' || c == 'I' || c == 'O' || c == 'U') {
                n++;
            }
        }
        return n;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Text: ");
        String text = sc.nextLine();
        System.out.print("Shift: ");
        int shift = Integer.parseInt(sc.nextLine().trim());
        System.out.println(verschluesseln(text, shift));
        System.out.println("Vokale: " + zaehleVokale(text));
    }
}
