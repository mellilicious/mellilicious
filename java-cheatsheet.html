    javac übersetzt Quellcode in Bytecode (.class), java führt ihn auf der JVM aus. jshell eignet sich zum schnellen Ausprobieren.

    Klassen & OOP

    Klasse mit equals / hashCode

    Eine Klasse bündelt Daten (Felder) und Verhalten (Methoden). Der Konstruktor initialisiert das Objekt, this meint das aktuelle Objekt. equals und hashCode definieren, wann zwei Objekte gleich sind (wichtig für HashMap und HashSet).

    public class Person {
    private String name;
    private int age;
    private static int count = 0;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
        count++;
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    @Override
    public String toString() { return name + " (" + age + ")"; }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof Person p)) return false;
        return age == p.age && Objects.equals(name, p.name);
    }

    @Override
    public int hashCode() { return Objects.hash(name, age); }
}

    Einfaches DAO

    public class ProduktDao {
    private final DataSource ds;
    public ProduktDao(DataSource ds) { this.ds = ds; }

    public Optional<Produkt> findById(long id) throws SQLException {
        String sql = "SELECT id, name, preis FROM produkt WHERE id = ?";
        try (Connection con = ds.getConnection();
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setLong(1, id);
            try (ResultSet rs = ps.executeQuery()) {
                return rs.next()
                    ? Optional.of(new Produkt(rs.getLong("id"),
                                              rs.getString("name"),
                                              rs.getBigDecimal("preis")))
                    : Optional.empty();
            }
        }
    }
}

    public Map<String, String> ungueltig(MethodArgumentNotValidException e) {

    public List<Produkt> alle() {
        return jdbc.query("SELECT id, name, preis FROM produkt",
            (rs, i) -> new Produkt(rs.getLong("id"),
                                   rs.getString("name"),
                                   rs.getBigDecimal("preis")));
    }

    public int neu(String name, BigDecimal preis) {
        return jdbc.update(
            "INSERT INTO produkt (name, preis) VALUES (?, ?)", name, preis);
    }
}

    Best Practices

    Java

    • Felder private, Zugriff über Getter oder record
    • Immutability bevorzugen (final, List.of, record)
    • equals() und hashCode() immer zusammen überschreiben
    • Gegen Interfaces programmieren: List<String> l = new ArrayList<>()
    • try-with-resources für alles AutoCloseable
    • Keine leeren catch-Blöcke
    • Optional als Rückgabetyp statt null
    • Namen: Klassen PascalCase, Methoden camelCase, Konstanten UPPER_SNAKE_CASE

    JDBC & Spring

    • SQL nur mit PreparedStatement, nie mit String-Konkatenation
    • Verbindungen über einen Pool, immer schließen
    • Konstruktor-Injektion statt Feld-@Autowired
    • Entities nicht direkt als API-Antwort, lieber DTOs oder Records
    • Transaktionen im Service, nicht im Controller
    • Passwörter und Schlüssel über Umgebungsvariablen, nicht in Git
    • ddl-auto: validate plus Flyway/Liquibase für Schema-Änderungen
    • LAZY-Beziehungen beachten (N+1-Problem, JOIN FETCH)

    Keine Treffer. Anderen Suchbegriff versuchen.
    Java 21 / Spring Boot 3. Beispiele sind verkürzt, Imports sind weggelassen.
